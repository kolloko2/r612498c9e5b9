# Приёмка на реальном учебном стенде

Статус: **не выполнена — Asterisk и телефон 201 не предоставлены в текущую среду**.
Локальные mock проверки не изменяют этот статус. Не устанавливайте TOPOLOGY_VERIFIED на основании одних unit тестов.

## Первый этап без STT и TTS

- [ ] Записаны версия Asterisk 22.x (не ниже 22.8), конфигурация кодеков и модель телефона.
- [ ] Контакт 201 зарегистрирован, отсутствуют внешние PSTN маршруты.
- [ ] POST /calls вызывает звонок на физическом телефоне/softphone.
- [ ] До ответа и до MEDIA_START всех каналов call.connected не отправляется.
- [ ] После ответа слышен пятисекундный тестовый тон 997 Гц.
- [ ] Во время теста записано не менее пяти секунд operator input, оператор говорил.
- [ ] operator.wav прослушан: голос присутствует, цифровой возврат собственного output отсутствует.
- [ ] caller.wav прослушан: тестовый тон присутствует.
- [ ] Сохранены JSON анализа и результаты прослушивания; акустическое эхо проверено с гарнитурой.
- [ ] После hangup нет оставшихся каналов/мостов на АТС.

## Разговорный режим после первого этапа

- [ ] TOPOLOGY_VERIFIED=true установлен только после положительного первого этапа.
- [ ] Opening caller.reply слышен как речь с выбранным TTS, а не mock тон.
- [ ] Реальный STT правильно распознаёт русский язык и отправляет только финальную фразу.
- [ ] Повторный reply_id не воспроизводится.
- [ ] Barge-in во время длинного ответа прекращает слышимый TTS и сохраняет начало речи оператора.
- [ ] should_interrupt=true запускает приоритетный ответ во время операторской речи.
- [ ] environment.update слышимо меняет фон/качество в телефонном направлении.
- [ ] WAV доступны Backend; recording.ready приходит после их финализации.
- [ ] Разрыв Backend WS вызывает ограниченный reconnect и не создаёт второй звонок.
- [ ] Ошибка STT/TTS вызывает fallback либо voice.error и корректное завершение.
- [ ] Hangup очищает inference процессы, media sockets и CallContext.
- [ ] На каждой реплике сохранены latency метрики; отсутствующие корреляции не подменены оценками.

## Технические ограничения

Энергетический VAD, качество Vosk/Piper, акустическая задержка и примерные Asterisk конфигурации требуют измерений на выбранном оборудовании. Поиск цифрового self-loop в mock записи проверяет приложение, но не доказывает корректность аудиодрайвера/телефона. Текущая реализация не даёт автоматического failover самой АТС или восстановления звонка после рестарта Voice.
