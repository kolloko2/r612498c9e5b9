# API внешнего ИИ

База: `http://127.0.0.1:8001/api/v1/integration`.
OpenAPI: `http://127.0.0.1:8001/docs`, раздел **External AI**.
Все запросы требуют `Authorization: Bearer <API_TOKEN>`. Токен берётся сервером интеграции из `/etc/voice-gateway.env`; не помещайте его в браузер или URL. Доступ с другого компьютера требует отдельной настройки сети и TLS; сейчас используется локальное подключение.

Роли: `operator` — человек, говорящий в микрофон MicroSIP; `victim` — пострадавший, которого озвучивает внешний ИИ. Режим `external` отключает встроенный диалог и не зависит от его доступности. Сам ИИ в это API не встроен.

## Методы

| Метод | Путь | Назначение |
|---|---|---|
| POST | `/calls` | Создать звонок на 201 в режиме external |
| GET | `/calls/{call_id}` | Статус и весь диалог, включая сохранённый |
| POST | `/calls/{call_id}/speak` | Озвучить точный текст пострадавшего |
| POST | `/calls/{call_id}/stop` | Прервать речь и очистить очередь |
| POST | `/calls/{call_id}/hangup` | Завершить звонок |
| GET | `/calls/{call_id}/events` | Поток событий SSE |
| GET | `/calls/{call_id}/events?follow=false&after=0` | Порция событий JSON, до 200 за запрос |

Создание:
```json
{"session_id":"<новый UUID>","extension":"201"}
```
Ответ содержит `call_id`, `session_id`, `status`. Примите звонок в MicroSIP и дождитесь `status=active` или соответствующего `call.updated`. Повтор создания с тем же session_id возвращает тот же активный звонок; после завершения новая попытка может создать новый call_id.

Озвучивание:
```json
{"message_id":"<новый UUID>","text":"Помогите, у меня в квартире пожар!","interrupt":false}
```
Ответ HTTP 202 означает только помещение в очередь. Повтор того же message_id и текста во время активного звонка не озвучивает реплику повторно. Повтор ID с другим текстом даёт 409. `interrupt=true` сначала очищает текущую речь и очередь. UUID сообщений должен быть уникальным в пределах звонка.

## События

`call.created`, `call.updated`, `operator.partial`, `operator.final`, `operator.error`, `playback.queued`, `playback.playing`, `playback.played`, `playback.interrupted`, `playback.error`.

```json
{
  "event_id":"42",
  "call_id":"<UUID>",
  "session_id":"<UUID>",
  "type":"operator.final",
  "time":"2026-09-09T10:00:00+00:00",
  "payload":{"id":"<UUID реплики>","role":"operator","text":"Назовите адрес","status":"recognized"}
}
```

Промежуточные и окончательные результаты одной фразы имеют одинаковый `payload.id`: обновляйте сообщение, не создавайте дубль. Передавайте в ИИ окончательный текст из `operator.final`.

Сохраняйте `event_id` обработанного события. При переподключении передайте `Last-Event-ID` или `after`. Номера монотонные, но могут иметь пропуски (общий счётчик для всех звонков). При JSON-опросе вычитывайте порции до пустой; при повторной доставке дедуплицируйте по event_id. Клиент отвечает за сохранение курсора и повтор команд; это не гарантия exactly-once между ИИ и сервером.

`playback.playing` — первый аудиокадр отправлен в Asterisk. `playback.played` — Asterisk подтвердил окончание буферизованного воспроизведения. Это не подтверждение, что человек услышал звук. `stop` может привести к `playback.interrupted`. Микрофон продолжает распознаваться во время TTS. Внешний ИИ сам решает, нужно ли прерывать речь командой stop.

Ошибки: 401 — токен, 404 — неизвестный звонок, 409 — звонок не активен/не тот режим/конфликт ID, 422 — неверные параметры, 429 — очередь заполнена. Для поиска статуса завершённого звонка используйте GET интеграции: история сохраняется на диске.

## Подключение

Пример: `tools/external_ai_client.py`. Он создаёт звонок, озвучивает заданную начальную реплику и печатает окончательные ответы оператора. В месте вызова `on_operator` подключается ваш ИИ; полученный от него текст отправляется методом `speak`. Тексты не исполняются как команды ОС.

Альтернатива: на странице `http://127.0.0.1:8002` до звонка выбрать «Внешний ИИ — пострадавший». Полученный call_id виден под чатом. Этот режим не запускает встроенный сценарий. Встроенный сценарий тоже исправлен: бот играет пострадавшего, человек — оператора.
