# Документация проекта

Двенадцать документов: основное руководство для жюри и одиннадцать подробных руководств и описаний. Формуляр и документы сдачи и приёмки исключены. Дата выпуска 28.09.2026. Разработчик и ответственный за документацию — Кодзаев Николай Петрович.

Редакция соответствует программной версии v1.0 от 27.09.2026. Исходные тексты находятся в `source/`, основания — в [sources.md](sources.md). Документы не меняют конфигурацию программы и PostgreSQL.

Локальный результат: `output/documentation-2026-09-28/`. Архив передачи: `output/112_AI_Trainer_Документация_2026-09-28.zip`. Начинать чтение с `12_Руководство_для_жюри.pdf` или `index.html`.

В этой редакции убраны листы регистрации изменений и пустые блоки согласования. Основное руководство оформлено свободно, без подписи и служебного титула. В отдельных документах подпись вставляется из локального PNG через `TRAINER_DOC_SIGNATURE`; исходный файл подписи не копируется в репозиторий.

## Воспроизведение

1. Запустить `tools/documentation/build.py` в Python с python-docx и lxml.
2. Выполнить рендер каждого DOCX штатным `render_docx.py` среды подготовки документов с `--emit_pdf`.
3. Обновить содержание через `tools/documentation/finalize.py --toc`, повторить сборку и рендер; проверить страницы и стабильность содержания.
4. Получить снимок библиотек `tools/documentation/inventory.py` при работающем стенде.
5. Выполнить `tools/documentation/finalize.py --package` после визуальной проверки всех страниц.

Для изолированного Linux-рендера подготовлен `tools/documentation/Dockerfile.render`. Он не является сервисом продукта. Шрифты Times New Roman подключаются с разрешённого локального источника; шрифтовые файлы в архив не включаются.

Иллюстрации в `screens/` сняты с реального интерфейса и содержат только синтетические сведения. Скрипт подготовки иллюстраций создаёт отдельное занятие; после съёмки его завершает `finish_capture.py`. Не запускать подготовку повторно для обычной пересборки документов.
