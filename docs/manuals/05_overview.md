## Назначение {#purpose}

Тренажёр диспетчера ДДС учит дежурно-диспетчерскую службу работать с карточками происшествий от Службы 112. Обучаемый работает на рабочем месте, которое повторяет настоящий АРМ ДДС: принимает карточку, направляет бригаду, докладывает по телефону, отражает ход работ и закрывает карточку.

Искусственный интеллект выполняет работу, которую обычно делает преподаватель:

- составляет новые учебные карточки, у каждого обучаемого своя;
- играет собеседников по телефону: начальника смены, руководителя организации, бригаду, специалиста, заявителя — если звонок ему разрешил преподаватель;
- оценивает действия обучаемого и даёт рекомендации, что потренировать дальше.

Все учебные данные вымышленные. Реальные данные Службы 112 в тренажёре не используются.

## Функции и возможности {#functions}

### Обучаемый

- работа в АРМ ДДС: журнал происшествий, карточка от Службы 112 без права редактирования, статусы своей службы, бригады, доклады бригады;
- карточка от ИИ в любой момент, без преподавателя;
- телефон: голосовые разговоры через IP-телефон MicroSIP или виртуальный телефон на сайте (зелёный кружок рядом с часами), справочник ДДС; без гарнитуры — запасной текстовый режим;
- обучение работе с интерфейсом: тур по окнам и кнопкам, подсказки наставника;
- результат после каждой карточки: оценка, проверка каждого действия, рекомендации ИИ;
- история своих результатов и типичных ошибок.

### Преподаватель

- группы обучаемых и рабочие места;
- занятие, в котором карточки формирует ИИ, или занятие по выбранным сценариям;
- создание нового упражнения с помощью ИИ и его правка перед публикацией;
- телефонный справочник ДДС для каждого сценария: до 10 собеседников, что каждый знает и что обучаемый должен ему сообщить;
- наблюдение за группой в реальном времени, режим «Делай как я»;
- разбор каждой попытки, экспертная оценка, статистика группы, выгрузка в Excel;
- методические материалы, на которые ИИ ссылается в рекомендациях.

### Администратор

- учётные записи и роли, политика входа, двухфакторный вход;
- состояние служб, резервные копии, журналы;
- учебные номера телефонов, настройки языковой модели, обновление.

## Как проходит занятие {#flow}

1. Преподаватель создаёт занятие для группы с отметкой «Карточки формирует ИИ» или обучаемый сам берёт карточку от ИИ.
2. Обучаемому приходит карточка от Службы 112. Он принимает её в работу или отказывает с причиной.
3. Назначает бригаду и звонит: руководителю бригады, начальнику смены, при необходимости руководителю организации и специалисту.
4. Бригада докладывает о выезде, прибытии, работах и результате. Обучаемый отражает каждый доклад статусом и комментарием.
5. Обучаемый докладывает начальнику о результате и закрывает карточку.
6. Тренажёр сразу показывает оценку. Через 3–5 минут появляются рекомендации ИИ.

## Состав {#structure}

| Часть | Назначение |
| --- | --- |
| Веб-приложение | страницы входа, кабинетов и рабочего места; работает в браузере Chrome, Яндекс.Браузер, Firefox |
| Сервер приложения | занятия, карточки, оценка, учётные записи, отчёты |
| База данных | учебные данные и результаты |
| Телефонная станция | учебные номера, звонки из браузера и с IP-телефонов |
| Голосовой модуль | распознавание речи обучаемого и озвучивание собеседников |
| Языковая модель | собеседники, новые карточки, рекомендации; работает на сервере, без интернета |
| Резервное копирование | ежедневные зашифрованные копии |

Все части работают на одном сервере в локальной сети учебного класса. На рабочих местах нужен только браузер и гарнитура.

## Требования {#requirements}

| Что | Минимум |
| --- | --- |
| Сервер | процессор 6 ядер, 32 ГБ памяти, 100 ГБ диска; видеокарта ускоряет ИИ, но не обязательна |
| Операционная система сервера | Linux (Ubuntu 22.04 и новее) или Windows 10/11 с Docker |
| Рабочее место | любой современный компьютер, браузер Chrome, Яндекс.Браузер или Firefox |
| Гарнитура | наушники с микрофоном для голосовых разговоров |
| Сеть | локальная сеть класса; интернет для занятий не нужен |

## Порядок установки {#install}

1. Скопировать тренажёр на сервер.
2. Подготовить настройки: пароли служб и учебных телефонов создаются автоматически.
3. Загрузить модели речи и языковую модель.
4. Собрать и запустить тренажёр одной командой.
5. Открыть адрес сервера в браузере и создать администратора.
6. При необходимости загрузить демонстрационные данные: преподаватель, обучаемые, группа, занятия.

Команды и подробности — в «Руководстве технического администратора», раздел «Установка».

## Возможные неисправности {#problems}

| Признак | Причина | Что сделать |
| --- | --- | --- |
| Сайт не открывается | службы остановлены или нет сети | проверить сеть, запустить тренажёр, см. руководство администратора |
| Браузер предупреждает о сертификате | на рабочем месте не установлен сертификат тренажёра | установить сертификат или продолжить вход для учебного стенда |
| Нет звука в разговоре | гарнитура не выбрана или браузер не получил доступ к микрофону | выбрать гарнитуру в окне телефона, проверить эхо-тестом 100 |
| «ИИ готовит для вас новую карточку» | запас карточек закончился | подождать минуту, следующая карточка будет готова |
| Рекомендации ИИ долго готовятся | сервер без видеокарты занят | подождать 3–5 минут; при сбое нажать «Повторить ИИ-разбор» |
| Собеседник отвечает коротко «Информация принята» | языковая модель не успела ответить | повторить вопрос короче; на сервере с видеокартой ответы быстрее |
| Обучаемый не видит занятие | он не в группе или занятие не начато | проверить группу и нажать «Начать» в карточке занятия |
