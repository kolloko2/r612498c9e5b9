# Запуск и доступность — 12 сентября 2026

Сайт: http://127.0.0.1:8002
API: http://127.0.0.1:8001/docs → External AI → Authorize (Bearer API_TOKEN).

Сайт автоматически запускается при входе пользователя zxc в Windows. Задача Планировщика `VoiceTraining-SiteSupervisor` поддерживает WSL и проверяет HTTP каждые 10 секунд. При трёх подряд неудачах запускается восстановление. Сам фоновый процесс повторно запускается Планировщиком при необходимости. Службы Linux перезапускаются при падении.

Проверка на этом компьютере: принудительное завершение процесса сайта → восстановление за 5.23 с; остановка Ubuntu/WSL → восстановление за 16.55 с. Это измерения теста, а не гарантия времени при любом сбое. Во время сна/выключения и до входа пользователя локальный сайт недоступен. Для круглосуточной доступности без включённого компьютера нужен отдельный постоянно работающий сервер.

Если после перезагрузки нужно пользоваться телефоном, запустите `Open-Voice-Chat.cmd` из этой папки. Он открывает MicroSIP, обновляет адрес SIP-сервера и открывает сайт. Активный звонок при повторном запуске сохраняется.

Роли: человек у микрофона — оператор 112, бот — пострадавший. Ручной режим: вводимый текст является репликой пострадавшего, автоматических ответов нет. Автоматический режим: встроенная модель играет Анну, сообщающую о пожаре. Внешний ИИ: управление репликами через API; встроенная модель не участвует. Сам внешний ИИ пока не подключён.

Проверено 37 тестов: API, авторизация, повторные сообщения, распознавание, подтверждение воспроизведения, восстановление истории/событий и роли. После оптимизации используется qwen3:1.7b на GPU с предварительной загрузкой. Проверка генерации ответа по сценарию заняла около 1,55 секунды; это время модели без распознавания и озвучивания. Полную задержку необходимо проверить в новом звонке.

Файлы диагностики: `site-supervisor.log` (только состояние служб, без текста разговоров), `recovery-verification.json`. История и записи разговоров сохраняются в Linux. Не удаляйте и не перемещайте папку проекта: задача автозапуска ссылается на её путь.

Отключить автозапуск можно в Планировщике заданий: отключите `VoiceTraining-SiteSupervisor` и завершите её выполнение. Автозапуск можно восстановить включением этой же задачи.
