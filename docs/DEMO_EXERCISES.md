# Подборка для демонстрации ДДС

В каталоге уже размечены 10 готовых карточек из билетов: структурированный адрес,
точная запись классификатора, собственная ДДС и оперативные вводные. Проверка
`test_curated_dds_cards.py` сверяет их с исходными адресами и маршрутизацией.

Для последовательной демонстрации через каталог преподавателя:

| Билет | Происшествие | Собственная ДДС | Что показать |
|---|---|---|---|
| ticket-02-1 | Задымление мусоропровода | 101 | Приём, бригада, доклад, вводные, результат |
| ticket-01-2 | Дерутся 10–15 человек | 102 | Передача адреса и обстановки, последовательность действий |
| ticket-05-2 | Случайный приём препаратов | 103 | Медицинский профиль и контроль доклада |

Опубликовать выбранные билеты из каталога, создать занятие в режиме готовых
карточек, назначить собственную группу. Для многозадачности выбрать несколько
одновременных карточек. В SIP-режиме каждому ученику требуется настроенный номер
АРМ. Текстовый режим удобен для проверки методики, но не заменяет показ IP-телефона.

Учебные задержки и критерии — авторская методика, а не официальные нормативы.
Оставшиеся билеты не объявляются вручную проверенными.

## Территориальный пример

`deploy/territorial-routes.demo.json` содержит синтетический «Учебный район» Москвы:
получатели района, округа и дополнительный образовательный получатель для объекта
«Учебная школа». Изолированный `--review-db` подключает его автоматически.
Для настоящей территории нужен утверждённый заказчиком справочник соответствий;
демонстрационный файл нельзя представлять как реальную организационную структуру.
