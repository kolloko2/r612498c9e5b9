# Project

Goal: a controlled, explainable training simulator using synthetic scenarios and optional SIP voice interaction.

Flow: validate scenario -> start session -> caller/events unfold -> finish -> transcript, timeline and evaluation report.

Roles: Backend owns domain, contracts and evaluation; Voice owns Asterisk/media/STT/TTS; Frontend owns scenario/session/report UX.

Definition of done: applicable checks, synchronized contracts, documentation, secret check and mock-mode coverage.
