# Перенос на машину защиты

## Что уже проверено на текущем ПК

- Наличие образов, моделей распознавания/синтеза, региональной офлайн-карты,
  служебных ENV и выбранной модели qwen3:8b: `python deploy/check_bundle.py`.
- Новый Backend запускается в отдельном read-only контейнере без сети, без
  рабочей БД и без рабочего ENV; health отвечает 200 в mock-режиме.
- АРМ: карточка, история службы, компактная строка статуса и инструменты
  открываются на 1920×1080 и 1280×720. Это не пиксельная сертификация.

## Для другой машины

1. Установить Docker Engine/Compose (или Desktop) и Ollama. Подготовить приватную
   локальную сеть, доступные ресурсы и свободное место под образы/карты/модели.
2. Передать код и образы через `deploy/manage.py export-images`, затем `docker load`.
   Передать `deploy/models` и `deploy/maps` отдельно: они не входят в образы/Git.
   Установить модели авторинга и телефона заранее (`python tools/fetch_llm.py`);
   по умолчанию это qwen3:8b и qwen3:4b-instruct-2507-q4_K_M. Отсутствие Интернета не должно
   запускать скачивание при первом учебном звонке.
3. Для нового независимого стенда создать собственные секреты и сертификаты по
   `DOCKER_DEPLOYMENT.md` и `TLS.md`. Не запускать `prepare.py` поверх действующего
   контура. Не переносить публично ENV, CA private key или резервные ключи.
4. Выбрать профиль TLS, корректный адрес сервера и SIP-адрес локальной сети.
   Телефон: TLS/5061 и SRTP, доверие публичному учебному CA. Каждый ученик —
   отдельный номер. Не использовать инструкции UDP/5060 для TLS-профиля.
5. Проверить Ollama из контейнера, файлы моделей, карту и здоровье сервисов.
   Voice по умолчанию ограничен 4 ГБ; это не гарантия ёмкости на 20 разговоров.
6. Пройти на целевой машине полное занятие и два параллельных разговора.
   Отдельно проверить физический микрофон/гарнитуру, переподключение и запуск
   без доступа в Интернет. Только после этого считать перенос принятым.

В текущей работе рабочий PostgreSQL не перенастраивается, не пересоздаётся,
резервная копия поверх него не восстанавливается. Независимая целевая машина
в этой сессии отсутствует; её готовность не выводится из проверки текущего ПК.
