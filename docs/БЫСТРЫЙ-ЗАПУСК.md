# Быстрый запуск на ноутбуке и показ

Инструкция для развёртывания с нуля на другой машине: что установить, как
поднять стенд, какие учётные записи и данные получаются и что показывать.

## 1. Что нужно на машине

**Обязательно:**

- Docker Desktop (Windows/macOS) или Docker Engine + Compose (Linux), запущен;
- Python 3.11 или новее — для скриптов подготовки и демонстрационных данных;
- около 4 ГБ свободного места под образы.

**Необязательно, но улучшает показ** — всё подтягивается скриптами:

```bash
python tools/fetch_models.py    # речевые модели, ~450 МБ (Vosk, GigaAM v2, Silero)
python tools/fetch_llm.py       # проверит Ollama и подтянет модель профиля
python tools/prepare_regional_map.py --download   # карта Москвы и области
```

`deploy/prepare.py` в конце сам печатает, чего не хватает и какой командой это
взять. Почему это не лежит в репозитории: речевые модели весят около 450 МБ, один
файл превышает лимит GitHub в 100 МБ, и распространять их — дело правообладателя;
карта — 912 МБ; веса модели Ollama держит у себя на хосте, чтобы они переживали
пересборку стенда и не попадали в образ.

Без всего этого стенд полностью работоспособен: занятие идёт, карточки
выдаются, нормативы считаются, доклад дежурному работает на детерминированных
ответах. Это важное свойство — оценка никогда не зависит от модели.

## 2. Развернуть

```bash
git clone https://github.com/kolloko2/112-ai-trainer.git
cd 112-ai-trainer
git checkout feat/voice-training-console

python deploy/prepare.py        # создаст приватный .env.docker со случайными паролями
python deploy/manage.py build   # соберёт образы
python deploy/manage.py up --plain
```

`--plain` поднимает стенд без TLS — для показа с ноутбука это проще всего:
адрес будет `http://127.0.0.1:3000`, браузер не спросит про сертификат.
Профиль с TLS, кластером из двух Backend и учебным каталогом LDAP включается
как `python deploy/manage.py up --tls --cluster --directory`, адрес тогда
`https://127.0.0.1:3000` с самоподписанным сертификатом.

**Если сборка падает на пути с кириллицей** (ошибка BuildKit про
`non-printable ASCII characters`) — создайте ASCII-ссылку на папку проекта и
собирайте из неё:

```powershell
New-Item -ItemType Junction -Path C:\t112 -Target "<путь к проекту>"
cd C:\t112
```

Проверить, что всё поднялось:

```bash
python deploy/manage.py status
curl http://127.0.0.1:3000/api/v1/health
```

Здоровых контейнеров должно быть девять в полном профиле и меньше в `--plain`.

## 3. Первый вход и демонстрационные данные

Откройте `http://127.0.0.1:3000/login`. На пустой базе откроется экран «Первый
запуск» — создайте администратора (пароль не короче 12 символов).

Затем одной командой создайте преподавателя, обучающихся, группу, сценарии из
учебных билетов и три занятия:

```bash
python tools/seed_demo.py --base-url http://127.0.0.1:3000 \
  --admin <ваш админ> --admin-password <его пароль>
```

Скрипт можно запускать повторно: он не создаёт дубликатов.

## 4. Что получилось — тестовые данные

Пароль у всех демонстрационных записей — `Trener112-2026`.

| Логин | Роль | Рабочее место |
| --- | --- | --- |
| `prepod` | преподаватель | — |
| `kursant1` | обучающийся | АРМ-1 |
| `kursant2` | обучающийся | АРМ-2 |

**Группа:** «Смена А (демо)» — оба курсанта.

**Сценарии:** шесть, опубликованы из учебных билетов датасета (билеты 1 и 2):
возгорание мусорного контейнера, драка, вызов скорой, задымление мусоропровода,
застрявший лифт, кража. Телефоны в них синтетические.

**Занятия:**

- **«Обучение: первое занятие ДДС с подсказками»** — идёт, начинать с него.
  Одна учебная карточка (прорыв трубы). Наставник справа показывает каждый шаг
  и подсвечивает, куда нажать: открыть карточку → «Принята» с комментарием →
  назначить бригаду → доложить по телефону → на каждый доклад бригады
  («выехали», «прибыли», «приступили», «закончили») поставить соответствующий
  статус и записать в комментарий, что сообщили → «Отметить отработанным» →
  «Завершить карточку» и прочитать разбор. На любой другой карточке ДДС
  наставник включается кнопкой «Практика с подсказками».
- **«ДДС: дежурная смена (демо)»** — идёт. Основной режим: готовые карточки,
  до 6 на человека, две одновременно; нормативы: открыть карточку за 30 секунд,
  первая запись (статус и текст) за 3 минуты. Курсанту
  Сидоровой назначено адресное задание.
- **«Полный цикл 112: приём вызова (текст)»** — идёт. Заявителя играет модель,
  разговор идёт с клавиатуры: ни SIP, ни речевые модели не нужны.
- **«Смешанное: ДДС + полный цикл 112 (телефон)»** — ждёт старта. Канал SIP,
  номера 201 и 202, обучающемуся разрешено переключать режим.

## 5. Два способа начать — выберите один

**Одиночная тренировка (проще, занятие не нужно).** Нажмите оранжевую кнопку
**«создать новую карточку»** справа вверху. В окне выберите сценарий
«Свободная тренировка: …» и **канал обращения**:

- *Текстовый диалог* — заявителя играет модель, вы пишете реплики с клавиатуры;
- *Телефон 201 · Voice / SIP* — настоящий звонок на софтфон с распознаванием
  речи и синтезом (нужен зарегистрированный MicroSIP, см. раздел 6).

Канал выбирается один раз и потом не меняется.

**Занятие от преподавателя (как в учебном классе).** Панель «Занятие группы»
сверху — это серия карточек, которую преподаватель выдаёт всей группе. Когда вы
нажимаете «Войти / ожидать старта», карточка приходит сама, а после её
завершения сразу выдаётся следующая, пока не кончится серия. Канал и режим
задаёт преподаватель при создании занятия — поэтому в занятии «Полный цикл 112
(текст)» разговор идёт текстом, а не по телефону. Что именно за занятие
выбрано, панель пишет прямо под собой: какие карточки, какой канал и что будет
после завершения.

## 6. Что показывать

**Основной режим ДДС — с `kursant1`.** Войти, указав номер АРМ (например,
АРМ-4) → «Перейти в рабочее место» → выбрать занятие «ДДС: дежурная смена» →
«Войти / ожидать старта». Прилетает готовая карточка, идёт таймер.

Показать по порядку:

1. **Норматив.** Через 30 секунд поле таймера краснеет — ровно как в настоящей
   системе.
2. **Горячие клавиши.** Удержать Alt — на блоках появляются подсказки. Alt+O
   уводит в описание, Alt+T в тип происшествия, Alt+Z открывает службы.
3. **Опросная карта.** Выбрать группу и признаки по вопросам «Где произошло»,
   «Что именно», «Обстоятельства» → определяется класс и автоматически
   подбираются службы. Основная подчёркнута двойной линией.
4. **Список оповещения** (Alt+Z): подобранные службы помечены, есть поиск.
5. **Доклад дежурному** — «Доложить по телефону». Сначала сказать неполно
   («Докладываю, улица Берзарина») — дежурный уточнит, чего не хватает, и
   завершить доклад нельзя. Потом добавить дом и тип происшествия — «Информация
   принята», доклад ложится в карточку телефонограммой.
6. **Перенаправить** и **Напомнить** — третье действие диспетчера и будильник.
7. **Завершить занятие** → отчёт с обоими нормативами.

**Преподаватель — `prepod`, `/portal`.** Показать: форму занятия с рабочими
местами и адресными заданиями; «Участники в реальном времени»; «Показ шага
группе» — режим «делай как я»; «Отчёт и участники» с временем реакции и
обработки, номером АРМ и числом ошибок ввода. Там же — **служба от внешней
системы**: открыть карточку обучающегося, добавить службу с основанием, и у
обучающегося она появится с пометкой ВИС.

**Остальное:** `/tickets` — 32 билета датасета и публикация в сценарии;
`/assessment` — оценки, тепловая карта, выгрузка XLSX; вводный тур сам
стартует на пустом рабочем месте.

## 7. Живая модель и телефон — если есть время

**Модель.** Установить Ollama, выполнить `ollama pull qwen3:4b`. В
`.env.docker` уже стоит `LLM_PROVIDER='ollama'` и профиль `standard`, адрес —
`http://host.docker.internal:11434`. После `python deploy/manage.py up`
в `/api/v1/health` появится `"model":"qwen3:4b"`. Без Ollama поставьте
`LLM_PROVIDER='mock'` — занятие пойдёт на детерминированных ответах.

**Телефон.** Занятие «Смешанное» использует SIP. Софтфон лежит в
`tools/windows-training/MicroSIP`, регистрация на `127.0.0.1` (порт 5060 в
`--plain`, 5061 в профиле TLS), внутренний номер 201, пароль — из
`SIP_ACCOUNTS_JSON` в `.env.docker`. Разрешённые кодеки: G.722, G.711a/u.

## 8. Если что-то не поднялось

| Признак | Причина и что сделать |
| --- | --- |
| `failed to connect to the docker API` | Docker Desktop не запущен |
| Сборка падает на `non-printable ASCII` | Кириллица в пути — сделать junction `C:\t112` (см. выше) |
| `Deployment ENV already exists` | `.env.docker` уже есть; это нормально, шаг пропускается |
| Voice «unhealthy» после пересборки Asterisk | Voice поднялся раньше Asterisk: `docker restart trainer112-voice-1` |
| `503` у `/api/v1/health` | Backend ещё стартует; подождать и повторить |
| Карта пустая | Нет пакета `deploy/maps/regional.sqlite` — он не хранится в Git |

## 9. Чего на стенде заведомо нет

Обработки входящих СМС, слоёв карты с камерами и техникой, конференции на
четырёх участников и перевода вызова с удержанием — это функции реальной АТС и
городских подсистем. Интеграций с действующими экстренными службами нет ни
одной: все данные синтетические, служба «от внешней системы» имитируется
преподавателем и стенд не покидает.
