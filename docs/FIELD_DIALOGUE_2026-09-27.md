# Разговор с бригадой — 27 сентября

Входящие оперативные доклады и исходящие запросы обстановки используют общий
собеседник `field_dialogue.py`. После начального доклада можно уточнять обстановку,
переспрашивать адрес и просить повторить сообщение. Контекст содержит текущий
доклад, ранее полученные оперативные сведения и исходные адресные поля карточки.
Будущие вводные, эталоны и оценки не передаются. Ответы не изменяют статусы и
не заменяют подтверждение прослушивания. Публичные схемы API не изменены.

Модель получает историю последних восьми реплик и ограничение ответа двумя
предложениями. Таймаут остаётся восемь секунд; mock/ошибка/таймаут используют
доступные факты вместо прежнего универсального «Доклад передан».
Вопросы о пострадавших проверяются по оперативным сведениям без модели:
отсутствие данных не означает отсутствие пострадавших. Остальные свободные
ответы ограничиваются промптом, а не формальным доказательством их истинности.

Повторный замер той же локальной qwen3:8b из рабочего Backend:

- Короткий контрольный запрос: 5,85 с.
- Адрес: 4,54 с, корректно назван учебный адрес.
- Завершение работ: 6,58 с, корректно сообщено, что работы продолжаются.
- Повтор доклада: 4,89 с, корректно повторены прорыв трубы и начало работ.
- В первой пробе ответ о пострадавших за 2,47 с ошибочно утверждал их отсутствие;
  после этого добавлена отдельная защита от такого вывода и регрессионный тест.

Замеры последовательные, только LLM, не полная задержка SIP/STT/TTS. В снимке
после пробы GPU RTX 5060 Ti: 1% нагрузки, 1361/8151 MiB памяти. Процессы по
маскам Ark*/ShooterGame* не найдены. Причинность прежнего замедления игрой
отдельно не измерялась; повторный замер не подтверждает многопользовательскую
производительность. PostgreSQL и его конфигурация не менялись.
