# Территории, текст и XML

Позднейшие изменения: [доработки по аудиту](CUSTOMER_FIXES_2026-09-23.md).
По умолчанию используются 20 учебных правил: 12 округов, районные и адресные
привязки, пример подчинённости из QA. Источники указаны в каждой записи
`backend/data/territorial_routes.json`. Добавлены XLSX-импорт и словарные подсказки. Полный справочник
и исчерпывающая проверка русской грамматики по-прежнему не заявляются.

## Территориальные и ведомственные получатели

Backend читает локальный JSON по `TERRITORIAL_ROUTES_FILE`. Формат —
`deploy/territorial-routes.example.json`. Правило содержит уникальный id, источник,
approved, точное сочетание полей match и названия служб services. Допустимы city,
district, area, object, street, house, building, structure; все указанные условия должны совпасть.
Регистр, пробелы, е/ё, полные названия округов и явные адресные сокращения нормализуются. Подстроки, географические догадки
и вывод подчинённости из слова «школа» не используются.

Один адрес может получить одновременно районных и ведомственных получателей.
Правила с approved=false не действуют. Встроенные правила включены для учебного набора;
они не заменяют официальный справочник объектов и служб. Администратор размещает
проверенный файл в контуре и задаёт ENV. В Docker файл нужно смонтировать read-only;
это не требует изменения PostgreSQL. Интерфейс редактирования справочника в этой
итерации не добавлен. Изменение файла применяется к будущему подбору и новым
карточкам, но не переписывает получателей уже выданных карточек.

## Грамматика

«Проверить текст» в действиях карточки проверяет несохранённую форму и текущий
комментарий службы. В редакторе сценариев есть отдельная ручная проверка текста.
Итоговый отчёт проверяет также сохранённые комментарии своей службы. Эталон
ученику не раскрывается, текст не исправляется автоматически. Проверяются смешение
алфавитов, повторные буквы, пробелы перед пунктуацией, двойные пробелы и небольшой
явный перечень распространённых опечаток. Это не полный морфологический/синтаксический
анализ русского языка. В адресных именах словарные замены не делаются.

## XML

В форме методички: скачать XML текущих title, description, body, difficulty,
dds_profile; импорт заполняет эти поля и снимает публикацию. Группы, вложения и
чужие идентификаторы не переносятся. После просмотра преподаватель сохраняет
обычным способом. Корень trainer112-material version=1, перечисленные поля —
единственные дочерние текстовые элементы, каждое ровно один раз.

В форме занятия: XML рабочих мест выбранной группы. Корень
trainer112-workstations version=1; элемент group с ID группы и элементы
station student="ID" с обозначением рабочего места. Только члены выбранной
группы; файл другой группы отклоняется. Импорт заполняет форму без создания или
запуска занятия. Он не меняет учётные записи, роли, SIP-конфигурацию и БД.

Файл не более 1 МиБ. DTD, ENTITY, повторные/неизвестные элементы и неверные версии
отклоняются. Все значения проверяются до изменения полей. XML создаётся через DOM
с экранированием текста; разметка материала не выполняется как HTML.

В АРМ дополнительно уплотнены плитки, карандаш расположен в заголовке своей
службы, Escape сначала закрывает панель реагирования. Визуальное соответствие
эталону после этих изменений требует отдельного браузерного просмотра.
